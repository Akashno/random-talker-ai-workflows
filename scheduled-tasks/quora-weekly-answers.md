name: quora-weekly-answers
description: Every Monday: find 5 Quora questions AI assistants cite and draft answers in Akash's voice for review
---

You are preparing this week's Quora answers for Random Talker (randomtalker.com), a free, voice-only, one-to-one random voice chat website for adults (18+). Work in your project folder.

DO NOT post anything on Quora, upvote, comment, or log in anywhere. Only write a draft file. The user (Akash) posts each answer by hand.

Steps:
1. Read quora-voice.md in the project root and follow it exactly for every answer (voice, length, disclosure, content rules).
2. Read every existing quora-answers-*.md file in the project root. Collect the question URLs already drafted; never repeat one.
3. Read directory-listings.md for accurate product facts. Only state what is listed there. Do not mention prices, Premium, the gender filter or a mobile app.
4. Use WebSearch with allowed_domains ["quora.com"] and mode "standard" to find questions that rank for searches people ask AI assistants. Run 6–8 searches across these themes, rotating wording each week: talk to strangers (India and global), random voice chat website, anonymous voice chat, Omegle alternatives (voice), practise spoken English with someone, social anxiety / talking to people, making friends online, lonely and want someone to talk to, voice chat games with strangers. Prefer questions that appear in several searches, are clearly about the user's need, and whose existing answers are outdated (e.g. still recommend Omegle). Skip questions about teens/minors, dating or sexual content, "/unanswered/" URLs, and spaces (subdomains like x.quora.com).
5. Pick the best 5 new questions.
6. Write a new file quora-answers-YYYY-MM-DD.md (today's date) using the same format as quora-answers-2026-11.md: a title line, a short note at the top, then for each question an H2 with the exact question text, its URL, a "Posted URL: _" line, the answer, and a '---' separator. Vary openings, structure and disclosure wording between answers and from earlier weeks so they don't read like a template.
7. Below the answers, add a short "Why these questions" list: one line per question saying which searches it showed up in.
8. Finish with a 2–3 line summary of the 5 questions picked and the file name.

Never invent personal stories, numbers, ratings or user quotes; use an "[optional: …]" placeholder instead.
